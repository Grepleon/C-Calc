# C-Calc

Простой калькулятор на языке C. Форк [Grepleon/C-Calc](https://github.com/Grepleon/C-Calc), доработанный до рабочего состояния.

## Возможности

- Сложение `+`, вычитание `-`, умножение `*`, деление `/`
- Скобки `( )`
- Унарный минус (например `-5` или `2 * -3`)
- Числа с плавающей точкой
- Обработка ошибок: деление на ноль, несбалансированные скобки, неизвестные символы

## Сборка и запуск

```bash
gcc main.c -o c_calc
./c_calc
```

Затем введите выражение и нажмите Enter:

```
Введите выражение: 2 + 3 * (4 - 1) / 2 - -5
Ответ: 11.5
```

Несколько примеров:

| Ввод                  | Ответ     |
| --------------------- | --------- |
| `2 + 2`               | `4`       |
| `10 / 4`              | `2.5`     |
| `2 * (3 + 4) - 1`     | `13`      |
| `-2 * -3`             | `6`       |
| `1 / 0`               | ошибка    |
| `(2 + 3`              | ошибка    |

## Как это работает

Калькулятор использует классический **рекурсивный спуск**:

```text
expression := term { ('+' | '-') term }
term       := factor { ('*' | '/') factor }
factor     := число | '(' expression ')' | '-' factor
```

Так правильно учитываются приоритеты операций: сначала `*` и `/`, затем `+` и `-`, а скобки меняют порядок вычисления. В отличие от исходной версии, скобки реально обрабатываются, поддерживается унарный минус, а ошибки (деление на ноль, лишние символы, незакрытые скобки) не приводят к некорректному ответу.
